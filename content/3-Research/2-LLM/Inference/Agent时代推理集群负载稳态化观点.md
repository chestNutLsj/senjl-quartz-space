# 背景
之前的认知：AI 训练集群的负载特征是“稳态计算 + 周期性 checkpoint 抖动”；AI 推理集群的负载特征与互联网应用类似，存在显著昼夜节律。

# 新观点
现在每个人都有一批 Agent 在日夜运行（例如为了最大化 subscription 使用率），推理任务正在从“即时响应型”转向“后台持续型”。

因此，推理集群负载可能正在失去昼夜区分度，并逐渐呈现出类似训练集群的稳态特征。

# 延伸判断
虚拟机时代可能会被弱化，LLM Agent 有机会成为云计算的新一层关键封装。

# 待验证
> [!question] 后续如何证明？
> - 收集学术论文（推理请求到达模式、Agent 长任务行为、数据中心时序负载）
> - 收集行业资料（云厂商/推理平台公开负载曲线与案例）
> - 对比训练集群与推理集群在时间尺度上的稳定性指标（峰谷比、方差、P95/P99 波动）
